Langkah pemasangan

  1. Buat Google Spreadsheet baru → Ekstensi → Apps Script.
  2. Hapus isi file kode, tempel seluruh isi Code.gs, ganti PIN_GURU, lalu simpan.
  3. Pilih fungsi siapkanSheet → Jalankan → izinkan akses.
  4. Terapkan → Deployment baru → Aplikasi web. Jalankan sebagai: Saya. Akses: Siapa saja.
  5. Salin URL Aplikasi Web (berakhiran /exec).
  6. Di index.html, cari baris var API_URL lalu tempel URL tersebut di antara tanda kutip.
  7. Unggah ke GitHub Pages dengan nama file persis index.html.

Masuk Siswa

Aturan Ujian

  1. Waktu mengerjakan untuk . Waktu habis = jawaban dikumpulkan otomatis.
  2. Jawaban tersimpan di HP-mu. Internet hanya dipakai saat masuk dan saat kumpul.
  3. Jangan keluar dari halaman ini, membuka aplikasi lain, menarik notifikasi, memakai layar terbagi (split screen), atau menutup/memuat ulang halaman.
  4. Setiap pelanggaran diberi peringatan. Pada pelanggaran ke-3 kamu otomatis dikeluarkan dan jawabanmu langsung dinilai.
  5. Jangan hapus data browser dan jangan pakai mode samaran (incognito).
  6. Jika halaman tertutup tidak sengaja, buka lagi alamat ujian di HP yang sama lalu tekan Masuk dengan nama, kelas, dan absen yang sama.
  7. Tombol Ragu-ragu menandai soal yang ingin kamu periksa lagi.
